# Export examples

These two documents demonstrate WCSpedia's PDF and editable Word export layout using fictional people and illustrative job-aid content. They are not approved business procedures.

`credit-approval-checklist.pdf` contains selectable text, a Citi cover with document-control and review/approval tables, a body page, clickable source/attachment links and page numbers.

`credit-approval-checklist.docx` contains editable Word paragraphs, headings, lists and tables with the same content and controls. The files were generated using the pinned browser libraries used by the application and rendered and checked before packaging.

The source URL in these examples is a placeholder. Use the document's **Export document** action to export the currently displayed version and real configured source URL. See `../EXPORTS.md` for implementation and attachment-hosting instructions.
